# Known Gaps

**Built, but not proved** — plus limitations accepted knowingly. Read this before relying on
something, and before claiming it works.

An entry is a statement about the strength of the *evidence* behind working code, not a bug report.
If something is actually behaving wrong, it belongs in [`bug/`](bug/).

Add an entry **in the same change that creates it**. If a checklist item was ticked on weaker
evidence than it asked for, say so in the task's Result section *and* open an entry here. A caveat
that lives only in a chat message does not exist.

When you clear one: **delete the entry** and say where the proof lives. The length of this file is
a real signal — a gap lingering because closing it was inconvenient is exactly the failure this
register exists to prevent.

Ids are never reused.
