# Open Questions

Decisions waiting on the owner. Every entry needs full context, a plain user-side scenario, and
concrete options — the framework is in [`AGENTS.md` §4](../AGENTS.md), and the skeleton is in
[`templates/register-entry.md`](templates/register-entry.md).

An open question blocks **only the checklist item that depends on it** — never the whole task,
never the plan. Mark that item `[~] blocked → OQ-n` and build everything else.

When one is answered: record the answer in the plan or task that consumes it, then **delete the
entry from this file**. This file only ever holds what is still open, so its length is a real
signal.

Ids are never reused, even after an entry is deleted.
