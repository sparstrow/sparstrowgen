# Shots

Generated design directions, one folder per round: `<YYYY-MM-DD>-<slug>/`.

Each folder holds the images (`A-*.png`, `B-*.png`, …) and a `README.md` recording what each
direction optimised for, which one won, and — the part that matters — **why the others lost, in
the owner's own words**.

Read the earlier rounds before writing new prompts. A direction already rejected should not be
generated again, and a preference stated twice belongs in `DESIGN.md` as doctrine rather than
being rediscovered every round.

Produced by the `design-shotgun` skill. See [`docs/Decisions.md`](../../docs/Decisions.md) D-012.
